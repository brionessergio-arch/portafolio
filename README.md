# 🚀 Portafolio Profesional — Sergio Briones

Portafolio profesional construido con **Astro** y desplegado en **Cloudflare**.

## 🛠️ Uso local

```bash
npm install
npm run dev
```

## ☁️ Desplegar en Cloudflare

1. Sube a GitHub
2. Cloudflare Dashboard → Workers & Pages → Create → Import a repository
3. Build command: `npm run build` | Output directory: `dist`
4. Deploy
